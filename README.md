# Grover's Quantum Search Algorithm

**Version:** 1.0

## Overview

This project implements Grover's unstructured search algorithm using [Qiskit](https://qiskit.org/). It explores the principles of quantum computation and demonstrates how quantum search can outperform classical approaches for small search spaces.

The project focuses on analyzing how the probability of finding the correct solution changes with the number of Grover iterations.

## Objectives

- Implement Grover's algorithm in Qiskit.
- Understand quantum circuits, qubits, gates, and measurements.
- Analyze success probabilities for different iteration counts.
- Compare ideal and noisy quantum simulations.
- Explore execution on real quantum hardware through cloud-based quantum services.
- Investigate the impact of noise and hardware limitations on quantum algorithms.

## Technologies

- Python
- Qiskit
- Qiskit Aer
- Quantum circuit simulators
- IBM Quantum hardware (where available)

## Project Scope

The implementation focuses on small, unstructured search problems to provide a practical understanding of Grover's algorithm and its behavior in realistic quantum computing environments.
